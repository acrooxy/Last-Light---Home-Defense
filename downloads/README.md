# Local build and source backup

PulseRunAndroid.apk is the existing local debug APK, uploaded unchanged. It corresponds to the local source snapshot in ../archive/PulseRunAndroid-local-source.zip, not necessarily to the current android-app source on main.

The archive includes all local source, resources, Gradle configuration, scripts and wrapper. Generated build folders and caches are excluded. The current GitHub GameActivity.java is preserved.

The missing AppTheme resource and Gradle wrapper JAR have also been added to the main project.
