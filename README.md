# Last Light: Home Defense

A colorful top-down Android survival game written in Java. Defend your home from waves of zombies and zombie dogs, collect crystals, and upgrade your survivor and weapons between rounds.

## Build and run

Open this project in Android Studio, let Gradle sync, select the `android-app` run configuration and an Android emulator or device, then press Run.

## Gameplay

- Touch joystick movement and a dash ability
- Automatic targeting and firing
- One-minute rounds with upgrades between rounds
- Player and safehouse health, crystals, and weapon upgrades
- Zombie dogs and several humanoid zombie types
